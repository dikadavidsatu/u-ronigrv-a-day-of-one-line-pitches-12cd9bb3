One sentence that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun. The program writes the pitch to `/output/entry.txt` — that single sentence is the whole entry.

## Run it

```sh
node main.ts
```

`main.ts` validates the pitch first (one sentence, non-empty, at most 240 characters) and then writes it to `entry.txt` in the output directory (`OUTPUT_DIR`, default `/output`).
